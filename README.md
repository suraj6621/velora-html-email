# VELORA — Responsive Fashion HTML Email Campaign

## Overview

VELORA is a responsive fashion promotional HTML email campaign created as a hands-on HTML email development project.

## Features

- 600px table-based email layout
- Responsive 3-column product section
- Mobile column stacking
- Nested tables
- Responsive images
- Promotional content modules
- CTA buttons
- Outlook VML CTA fallback
- MSO conditional comments
- Email-specific layout and spacing techniques

## Technologies

- HTML5
- CSS3
- Responsive HTML Email
- Table-based layouts
- Inline CSS
- VML
